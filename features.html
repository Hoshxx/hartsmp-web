Java and Bedrock together

Everyone joins the same world, whatever they play on.

  • Geyser and Floodgate let phones, consoles and Windows Bedrock players in with no mods
  • Bedrock names show up with a dot in front, like .Steve
  • ViaVersion, ViaBackwards and ViaRewind let slightly older or newer Java clients connect

Jobs and money

Money comes from playing, not from a store.

  • 12 jobs: Miner, Farmer, Fisherman, Hunter, Builder, Crafter, Woodcutter, Digger, Explorer, Brewer, Enchanter and Weaponsmith
  • Hold up to 3 at once and level them up from /jobs browse
  • Daily earning cap that grows as your job levels grow
  • Killing players pays nothing

Player shops

Sell from a chest and a sign, even while you're offline.

  • ChestShop signs: ₱50 to set one up, ₱20 back if you remove it
  • 3% tax on trades keeps prices steady
  • /csn history shows what sold while you were away

Land claims

Claim your base so nobody walks off with your stuff.

  • RedProtect claims cost ₱1 per block
  • Up to 20 claims per player
  • StellarProtect logs block and container changes, so staff can roll back griefing

Fair play

We watch for cheating so you don't have to.

  • Whitelist only, with a login so accounts stay yours
  • Anti-xray hides ores from cheat clients, and NeoAntiXray alerts staff to odd mining
  • GrimAC checks movement and combat, built to leave Bedrock players alone

A smooth world

Built to run well and explore well.

  • Purpur 26.3 server software
  • Chunky pre-generated the world, so exploring doesn't cause lag spikes
  • A world border keeps everyone inside the generated area
  • Live squaremap web map for whitelisted members at hartsmp.art/map

Server events

Two plugins we wrote ourselves. Staff run them, so keep an eye on Discord.

HartSMP Lottery

Custom plugin
  • Staff open a round, and anyone can join with /lottery gui
  • Tickets are ₱50 each, or 5 for ₱250. More tickets, better odds
  • The winner takes 80% of the pot, and 20% goes to the server
  • Title screens and sounds announce each round and each winner

Demise

Custom plugin
  • Last player standing wins a cash prize
  • Staff start a round, and a horn sounds server-wide
  • Sword and bow hits on players don't count as eliminations
  • You go out to traps, the environment, mobs or natural causes, so build clever

Proximity voice chat

Talk to people near you with Simple Voice Chat. Java players install the mod from our Mods section.

Skins

SkinsRestorer keeps skins loading properly for everyone.

Lag check

Anyone can run /tps to see how the server is doing. 20 is perfect.
